# Frontend — Better Health

Web UI for **Better Health**, a clinic management and appointment scheduling system.

Full project docs (overview, architecture, stack, and how to run API + frontend) live in the [root README](../README.md).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm test   # Jest
npm run lint
```
